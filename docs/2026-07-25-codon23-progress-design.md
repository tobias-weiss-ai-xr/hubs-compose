# Codon 23: Progress Tracking — Design

## Overview

Real-time per-student progress tracking for chemistry VR labs. Tracks element navigation, experiment completion, quiz scores, and time spent per element.

## Architecture

Follows the same pattern as Codon 22 (Quiz):

- **Reticulum (Elixir)**: Ecto schema + migration + Phoenix channel handlers
- **Hubs (JS)**: hub-channel.js wrapper methods + React components

## Data Model

### `user_progress` table

| Column | Type | Notes |
|--------|------|-------|
| `user_progress_id` | `bigint` | PK, generated by `ret0.next_id()` |
| `account_id` | FK→accounts | nullable (anonymous sessions) |
| `hub_id` | FK→hubs | NOT NULL, cascade delete |
| `session_id` | `text` | NOT NULL, for anonymous fallback |
| `element_slug` | `text` | NOT NULL — identifies the element/experiment |
| `element_type` | `text` | `"element"`, `"experiment"`, or `"quiz"` |
| `status` | `text` | `"visited"`, `"started"`, `"completed"` |
| `score` | `integer` | nullable |
| `max_score` | `integer` | nullable |
| `time_spent_ms` | `integer` | cumulative, defaults 0 |
| `visited_count` | `integer` | defaults 1 |
| `metadata` | `jsonb` | flexible extra payload |

Indexes: `(account_id, hub_id, element_slug)` unique, `(hub_id)`, `(account_id)`

## Channel Events

1. **`track_progress`** — upsert progress row; broadcast `progress_updated` to room
   - Payload: `{element_slug, element_type, status?, score?, max_score?, time_spent_ms?}`
   - Validates: element_slug required, status in allowed values
   - Upsert pattern: delete existing + insert (same as Quiz submit_answer)

2. **`get_my_progress`** — return caller's progress for current hub
   - Returns list of progress entries

3. **`get_room_progress`** — teacher-only; all students' progress aggregated
   - Returns `{students: [{account_id, identity_name, entries: [...]}]}`

## Frontend

### `ProgressTracker` (background module)
- Hooks into hub-channel events: `navigate_element`, `quiz_started`, `quiz_ended`
- Tracks time spent per element (interval-based)
- Auto-sends `track_progress` on navigation and quiz completion

### `ProgressPanel` (React component)
- Teacher view: student list with completion % per element
- Student view: own progress checklist per element
- Bar-chart style results for quiz scores per element
