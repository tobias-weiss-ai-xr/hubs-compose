Analytics Dashboard (Codon 24)

Real-time classroom analytics for chemistry VR labs

Available Data

Based on the systems we've built, these data sources are available:

  • Quizzes — question, options, per-student answers, correct/incorrect
  • Progress — per-student: element navigation, time spent, completion status
  • Room sessions — active CCU, member counts (from existing hub_controller)
  • Enrollments — teacher/student role assignments
  • Annotations — student-added notes per element

First question: Who is this dashboard for?

A

Teacher Dashboard

Real-time view: who's in the room, what they've completed, quiz scores, per-student progress. Shows heatmap of element visits.

B

Teacher + Student Dashboard

Teacher sees all students. Students see their own stats: time spent, completed elements, quiz history, progress through worksheet.

C

Admin Dashboard

Cross-room analytics: aggregate across all rooms, per-class trends, usage stats over time. Less focus on real-time, more on historical.

Open http://localhost:64507 and click an option, then respond in the terminal.
